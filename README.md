# food-dataset-images-using-Resnet18-and-cnn-models

Developed and evaluated deep learning models for classifying food items from images. Leveraged ResNet-18 and a custom CNN architecture, applying image augmentation to enhance performance and reduce overfitting.

✅ Key Achievements:

Achieved 88% accuracy with a pre-trained ResNet-18, outperforming a custom CNN.
Applied image augmentation to improve model robustness.
Evaluated performance using accuracy, precision, and recall.
Identified areas for improvement, including regularization techniques for better generalization.

Skills: Convolutional Neural Networks (CNN), Transfer Learning, image augmentation, Image Segmentation, model evaluation, python, PyTorch
